# Third-party files used by the Reformat feature

These are copied unmodified. Nothing here is written by the CiteProof project.

## Citation Style Language styles (CC BY-SA 3.0), retrieved 2026-10-24

Source: https://github.com/citation-style-language/styles (the official style repository). Licence: https://creativecommons.org/licenses/by-sa/3.0/ . Each file names its authors and contributors in its own header. They are unchanged here, so ShareAlike applies to these files only, not to the rest of this project.

- `apa.csl`: APA Style 7th edition (sha256 3917def5fc951b10)
- `modern-language-association.csl`: MLA Handbook 9th edition (in-text citations) (sha256 e1432698ef28938d)
- `chicago-author-date.csl`: Chicago Manual of Style 18th edition (author-date) (sha256 002fade78d7e4fe9)
- `harvard-cite-them-right.csl`: Cite Them Right 12th edition (author-date/Harvard) (sha256 0ca3d2c7c881cd98)
- `ieee.csl`: IEEE Reference Guide version 11.29.2023 (sha256 b4c7619fc16c45a3)
- `american-medical-association.csl`: AMA Manual of Style 11th edition (sha256 d70f843d93c2b1e8)

## citeproc-py 0.11.1 (BSD 2-Clause), in `docs/py/citeproc/`

Source: https://pypi.org/project/citeproc-py/ (wheel sha256 086db0be0f09552b). Copyright 2011-2013 Brecht Machiels. The licence text is in `docs/py/citeproc/LICENSE`. Only the engine and its English locale files are included; its schema, bundled styles and scripts are left out. The English locale files come from the Citation Style Language locales project (CC BY-SA 3.0).

Note the spelling: `citeproc` is this third-party engine; `citeproof` is this project.
