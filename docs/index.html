How your data is handled
  • Your list, any catalogue file and the results stay in this tab. No server, account, cookies or analytics.
  • On opening, the page downloads its own files and the Python engine (Pyodide 0.29.5) from cdn.jsdelivr.net. Nothing you type is in those downloads.
  • Two optional Crossref lookups are off. If you turn one on and press Send, the DOIs, or the title, first author and year of references with no DOI, go to api.crossref.org. The page shows exactly what first.

About catalogues

A catalogue is a list of records you trust. Each reference is looked up by DOI; if it is not in the catalogue it gets no verdict. The sample has 7 real records, deliberately small.

    Download the sample (JSON)

    Your own file. JSON is CiteProof's format: a list of records, each with a doi. CSV is a convenience of this demo: a header row with doi (required), title, authors, year, journal, retracted, provenance. Rows with no DOI are skipped. A blank retracted means “not known”.

    doi,title,authors,year,journal,retracted,provenance
10.1234/example,A study of things,Smith; Doe,2020,Journal of Things,false,My library
    Optional: look things up online off

    Both are off. Ticking a box sends nothing: after you check, the page lists exactly what it would send and waits for a Send button.

    Sends only DOIs to Crossref.

    Sends each such reference's title, first author's family name and year to Crossref. It suggests up to three matches; nothing is chosen for you.

    What exactly is sent, and what comes back?
    • Requests go to api.crossref.org, one at a time. Crossref also sees your IP address and the usual request headers. No email address, key or cookie is used.
    • Lookups are rate-limited. If Crossref asks the page to slow down, it stops and says so.
    • Results are added to the comparison for that run only and labelled as Crossref records. A DOI Crossref does not know is still “not found”, not “wrong”.
    • Title-search matches are suggestions. The result does not change until you press Use this DOI on one you have read.
    Available when the Python engine has loaded.

    What this does not check

    • Whether a reference is real. “Not found in this catalogue” says nothing either way.
    • Whether a source supports your claim. A reference can match a real record and still be cited for the wrong reason. (CiteProof's separate claims command only routes this to a person, and is not part of this demo.)
    • Your writing. It does not read your paper, and is not an AI or plagiarism detector.
    • Source quality or citation style. Only DOI, title, authors, year and journal are compared, by wording.
    • Retractions beyond what the catalogue says.
    • Pasted-text reading. This page's own reader can misread unusual layouts. Each result shows how it was read.
    • Decisions. Nothing here is an academic-integrity finding. A person decides.
