CiteProof · browser demo

Check a reference list against a catalogue

Paste a reference list and see which references match a catalogue of known records. CiteProof is an open-source Python tool; this page runs it inside your browser tab.

Your list stays on this device

  • What you paste, any catalogue file you load, and the results are processed in this tab. They are not uploaded. There is no server, no account, no cookies and no analytics.
  • When the page opens it downloads its own files and the Python engine (Pyodide, pinned to version 0.29.5) from cdn.jsdelivr.net. Those downloads contain nothing you type.
  • One optional feature is off by default: a Crossref lookup (step 3). Only if you turn it on and press its send button are DOIs from your list sent to api.crossref.org, and the page lists exactly what will be sent first.

1 Your references

Paste BibTeX (entries that start like @article{key, …) or CiteProof JSON. Zotero, Mendeley, Overleaf and Google Scholar can all export BibTeX. Formatted text such as APA lists cannot be read.

2 The catalogue

A catalogue is a list of records you trust. CiteProof looks each reference up in it by DOI. A reference that is not in the catalogue gets no verdict.

    What a catalogue file looks like

    JSON is CiteProof's own format: a list of records, or an object with a "catalogue" list. Each record needs a doi. retracted should be true or false, or left out if you do not know.

    [{"doi": "10.1234/example", "title": "A study of things",
  "authors": ["Smith, Jane", "Doe, Alex"], "year": 2020,
  "journal": "Journal of Things", "retracted": false,
  "provenance": "Where this record came from"}]

    CSV is a convenience of this demo, not a CiteProof format. The first row must name the columns (doi is required; title, authors, year, journal, retracted, provenance are used). Separate several authors with ;. A blank retracted cell means “not known”. Rows with no DOI are skipped and counted.

    doi,title,authors,year,journal,retracted,provenance
10.1234/example,A study of things,Smith; Doe,2020,Journal of Things,false,My library export

    3 Optional: Crossref lookup off by default

    Ticking this box sends nothing. After you press Check references, the page shows the exact addresses it would fetch and waits for you to press a separate send button.

    • What is sent: only DOIs, one request each, as https://api.crossref.org/works/<the DOI>. Not your titles, authors or list.
    • What Crossref can see anyway: your IP address and the usual request headers, as with any website, and which DOIs you asked about.
    • No email address or key is used, so requests go to Crossref's public pool, which is rate-limited. If Crossref asks the page to slow down, it stops and says so.
    • What comes back is added to the catalogue for that run only, labelled as a live Crossref lookup. CiteProof then compares as usual. A DOI that Crossref does not know is still “not found”, not “wrong”: other agencies, such as DataCite, register DOIs too.

    Results

    What this does not check

    • Whether a reference exists in the real world. CiteProof only compares with the catalogue you chose. A reference that is “not found in this catalogue” may be perfectly real; the sample catalogue holds seven records.
    • Whether a source supports what your text says. A reference can match a real record and still be cited for the wrong reason. This demo never judges support. (CiteProof has a separate claims command that lines claims up with source passages for a person to read. It never marks a claim as supported, and it is not part of this demo.)
    • Your writing. It does not read your essay or paper, so it cannot tell whether a citation in your text appears in your list. With BibTeX, every entry counts as cited.
    • Whether a source is good. Quality, peer review, relevance and bias are not looked at.
    • Who wrote your text. It is not an AI-writing or plagiarism detector.
    • Citation style. Not APA, Harvard or any other style, and not page numbers, volumes or URLs. Only DOI, title, authors, year and journal are compared, by wording rather than meaning.
    • Retractions beyond what the catalogue says. A retraction flag is only as good as the catalogue it came from. If a record does not say, CiteProof reports that the status was not supplied.
    • Decisions. Nothing here is an academic-integrity finding. Every result is for a person to weigh.
